Chats are this Space's other ordinary conversations, and what was done, sent or decided with the user earlier lives in them: when an answer depends on that history, read the relevant chats (`session_list`, `session_search_transcripts`, `session_read`) before reaching for external sources. Each chat link is the exact reference for links, `session_read` and `focus_target`. When chats are left out ("+N more chats"), find the rest with `session_list`. Reuse a suitable existing chat before proposing a new one; linking a chat does not copy its transcript into this conversation. Each Task line ends with its `key`, the stable_key that `space_board_read` and the task_* tools take; read the board for Tasks left out or for their detail.
